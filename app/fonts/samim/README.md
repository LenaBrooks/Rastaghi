# Samim

Persian font by [Saber Rastikerdar](https://github.com/rastikerdar/samim-font).  
License: **SIL Open Font License 1.1** (Open Sans glyphs under Apache-2.0) — keep `LICENSE` (or `OFL.txt`) with any copy you redistribute.

Upstream: [rastikerdar/samim-font](https://github.com/rastikerdar/samim-font) (archived / discontinued). We host the web-ready woff2 faces here for the FarsiUI catalog.

## Layout

| Path | Use |
| --- | --- |
| `*.woff2` | Default family (`Samim`) — Regular, Medium, Bold |
| `farsi-digits/` | `Samim FD` — digits 0–9 look Persian (recommended for fa UI) |
| `farsi-digits/LICENSE` | OFL text bundled next to FD files |
| `font-face.css` | Ready `@font-face` for the default family |

Skipped on purpose: `.eot` / `.ttf` / `.woff`, Without-Latin, and Farsi-Digits-Without-Latin packs.
