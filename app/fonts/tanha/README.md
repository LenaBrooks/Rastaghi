# Tanha

Persian font by [Saber Rastikerdar](https://github.com/rastikerdar/tanha-font).

**License (not OFL):** changes by Saber Rastikerdar are public domain; Roboto glyphs are Apache License 2.0; base faces are Bitstream Vera. Keep `LICENSE` with any copy you redistribute. The Bitstream Vera terms disallow selling the typeface by itself.

Upstream: [rastikerdar/tanha-font](https://github.com/rastikerdar/tanha-font?tab=License-1-ov-file) (archived / discontinued). We host the web-ready woff2 faces here for the FarsiUI catalog.

## Layout

| Path | Use |
| --- | --- |
| `Tanha.woff2` | Default family (`Tanha`) — Regular only |
| `farsi-digits/` | `Tanha FD` — digits 0–9 look Persian (recommended for fa UI) |
| `farsi-digits/LICENSE` | Upstream license text (required when redistributing) |
| `font-face.css` | Ready `@font-face` for the default family |

Skipped on purpose: `.eot` / `.ttf` / `.woff`, Without-Latin, and Farsi-Digits-Without-Latin packs.
