# Gandom

Persian font by [Saber Rastikerdar](https://github.com/rastikerdar/gandom-font).  
License: **SIL Open Font License 1.1** — keep `LICENSE` (or `OFL.txt`) with any copy you redistribute.

Upstream repo is archived / discontinued; we host the web-ready woff2 faces here for the FarsiUI catalog.

## Layout

| Path | Use |
| --- | --- |
| `Gandom.woff2` | Default family (`Gandom`) — Regular only |
| `farsi-digits/` | `Gandom FD` — digits 0–9 look Persian (recommended for fa UI) |
| `farsi-digits/LICENSE` | OFL text bundled next to FD files |
| `font-face.css` | Ready `@font-face` for the default family |

Skipped on purpose: `.eot` / `.ttf` / `.woff`, Without-Latin, and Farsi-Digits-Without-Latin packs.
