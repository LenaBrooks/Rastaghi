# Sorena (Farsi Digits)

English–Arabic / Persian **pixel** typeface by [Mohammad Darvishi](https://github.com/MDarvishi5124/Sorena); initial idea by Erfan Kheirollahi.  
License: **SIL Open Font License 1.1** — keep `LICENSE` / `OFL.txt` with any copy you redistribute.

Upstream: [MDarvishi5124/Sorena](https://github.com/MDarvishi5124/Sorena) · Demo: [mdarvishi5124.github.io/Sorena](https://mdarvishi5124.github.io/Sorena)

Ships the **Farsi-digits** Normal and Pixel web faces. Upstream also has non-FD and Fanum variants.

## Layout

| Path | Use |
| --- | --- |
| `SorenaFD-Normal.woff2` | FD Normal (primary) |
| `SorenaFD-Pixel.woff2` | FD Pixel (strict pixel grid) |
| `LICENSE` / `OFL.txt` | SIL OFL 1.1 (identical) |
| `font-face.css` | Ready `@font-face` |
