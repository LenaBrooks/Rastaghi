# Sepehr

Persian / Arabic font hosted by [googlefonts/sepehr-fonts](https://github.com/googlefonts/sepehr-fonts) (OFL-1.1).  
Based on DejaVu + Vazir; Persian glyphs redesigned by Saeed Rezaee.

Upstream: [googlefonts/sepehr-fonts](https://github.com/googlefonts/sepehr-fonts) · License: [OFL-1.1](https://github.com/googlefonts/sepehr-fonts/blob/main/OFL.txt)

Static web faces converted from upstream TTF (`fonts/`).
