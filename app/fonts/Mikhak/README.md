# Mikhak

Persian / Arabic–Latin semi-handwriting typeface by [Amin Abedi](https://github.com/aminabedi68/Mikhak).  
License: **SIL Open Font License 1.1** — keep `LICENSE` / `OFL.txt` with any copy you redistribute.

Upstream: [aminabedi68/Mikhak](https://github.com/aminabedi68/Mikhak) · demo: [aminabedi68.github.io/Mikhak](https://aminabedi68.github.io/Mikhak/)

This folder ships the **variable FD** face (`wght` + Kashida + Dot styles; Persian digits) for the FarsiUI catalog and `npx farsiui add font-mikhak`. Static weights and non-FD packs are omitted on purpose.

## Layout

| Path | Use |
| --- | --- |
| `Mikhak-FD.woff2` | Variable FD (from upstream `Mikhak-FD[DSTY,KSHD,wght].woff2`) |
| `LICENSE` / `OFL.txt` | SIL OFL 1.1 (identical) |
| `font-face.css` | Ready `@font-face` for self-host CSS |
