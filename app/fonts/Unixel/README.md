# Unixel

English–Arabic / Persian **pixel** typeface by [Mohammad Darvishi](https://github.com/MDarvishi5124/Unixel), inspired by Unifont with calligraphic Arabic structure.  
License: **SIL Open Font License 1.1** — keep `LICENSE` / `OFL.txt` with any copy you redistribute.

Upstream: [MDarvishi5124/Unixel](https://github.com/MDarvishi5124/Unixel) · Demo: [mdarvishi5124.github.io/Unixel](https://mdarvishi5124.github.io/Unixel/)

Only the Regular web face is shipped here.
