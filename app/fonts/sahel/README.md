# Sahel

Persian font by [Saber Rastikerdar](https://github.com/rastikerdar/sahel-font).  
License: **SIL Open Font License 1.1** — keep `LICENSE` (or `OFL.txt`) with any copy you redistribute.

## Layout

| Path | Use |
| --- | --- |
| `*.woff2` | Default family (`Sahel`) — Latin + Arabic digits |
| `Sahel-VF.woff2` | Variable weight |
| `farsi-digits/` | `Sahel FD` — digits 0–9 look Persian (recommended for fa UI) |
| `farsi-digits/LICENSE` | OFL text bundled next to FD files (required when redistributing) |
| `font-face.css` | Ready `@font-face` for the default family |

Skipped on purpose: `.eot` / `.ttf` / `.woff`, and Without-Latin packs.
