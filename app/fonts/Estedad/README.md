# Estedad

Persian / Arabic–Latin sans by [Amin Abedi](https://github.com/aminabedi68/Estedad).  
License: **SIL Open Font License 1.1** — keep `OFL.txt` with any copy you redistribute.

- Google Fonts (CDN / `next/font/google`): [fonts.google.com/specimen/Estedad](https://fonts.google.com/specimen/Estedad)
- Upstream: [aminabedi68/Estedad](https://github.com/aminabedi68/Estedad)

This folder ships the **variable** (`wght` 100–900) woff2 for `npx farsiui add font-estedad` / `next/font/local`. Static weight files are omitted on purpose.

## Layout

| Path | Use |
| --- | --- |
| `Estedad-wght.woff2` | Variable face (renamed from upstream `Estedad[wght].woff2`) |
| `OFL.txt` | SIL OFL 1.1 |
| `font-face.css` | Ready `@font-face` for self-host CSS |
